# Game Specification Template

## 23-Section Structure for Game Specifications

### Section 1: Concept Summary
- One-line concept
- Genre
- Target audience
- Core player fantasy
- Primary skill tested
- Session length
- Platform context

### Section 2: Repo Status
- Implementation status
- What works now
- What is partial/missing
- Evidence
- Confidence level

### Section 3: Current Implementation
- Flow
- Controls
- Mechanics
- Visuals/UI
- Gaps/Issues

### Section 4: Intended Design
- Educational goal
- Pedagogical approach
- Difficulty progression
- Accessibility
- Engagement
- Core Loop

### Section 5: Drift Analysis
- Where Implementation Matches Intent
- Where Implementation Exceeds Intent
- Where Implementation Falls Short
- Overall Assessment with %

### Section 6: Recommended Canonical Version
- Current Strengths to Keep
- Enhancements to Implement
- Experimental Features

### Section 7: Visual Identity
- Overall look
- Camera view
- Art style
- Mood
- Colors
- Environment
- UI style
- Active vibe

### Section 8: Screen Map
| Screen | Purpose | Elements |
|--------|---------|----------|

### Section 9: Controls
| Action | Input | Feedback |
|--------|-------|----------|

### Section 10: Core Mechanics
- Detailed mechanics
- Algorithms
- Scoring formulas

### Section 11: Rules
- Start conditions
- Objectives
- Allowed actions
- Restrictions
- Scoring
- Win/lose conditions

### Section 12: HUD / Gameplay UI
| Element | Purpose | Update |
|---------|---------|--------|
- Layout diagram

### Section 13: Feedback and Feel
- Success feedback
- Failure feedback
- During gameplay
- Streak/Progress feedback

### Section 14: Points / Rewards / Progression
- Points breakdown
- Final score calculation
- Rewards/Drops
- Easter Eggs
- Progression system

### Section 15: End States
- Correct/Success
- Wrong/Failure
- Timeout
- Game Complete

### Section 16: Parallel Modes / Alternate Implementations
- Mode A, B, C, etc.

### Section 17: Improvement Opportunities
- Low Cost
- Medium Effort
- Ambitious

### Section 18: Content Model
- Content structure
- Data/Levels

### Section 19: Technical Structure
- Main files
- Key components
- Logic functions
- Hooks used
- State management
- Dependencies

### Section 20: Gaps and Unknowns
| Gap | Inference | Confidence |
|-----|-----------|------------|

### Section 21: Implementation Notes
- Strengths to Preserve
- Architecture Patterns
- Testing Considerations
- Performance Notes

### Section 22: Acceptance Criteria
- [ ] Checklist items

### Section 23: Test Plan
- Manual gameplay tests
- CV control tests
- Fallback tests
- Edge cases
- Performance
